        <mda:meta type="title">Slatepath data workbench interface strings</mda:meta>
        <mda:meta type="info">Slatepath is a data analysis workbench for analysts who open a data set, draw a chart from it and pin the chart to a shared board. Its modules are Quarry, where data sets are browsed and opened, the chart editor, the compute cluster page, the storage page and the notification page. A scratch table is an analyst's own draft copy of a result set: it lives in the browser tab, it is not a database temporary table, and every entry that names it must say it the same way. Several action labels appear twice, once in a wide menu on a settings page and once in the narrow inspector rail at the edge of the screen, which is why some of them carry a display-width budget. Audience: analysts and data engineers working in a desktop browser.</mda:meta>
        <mda:meta type="standard">Keep the product name Slatepath and module names such as Quarry in Latin script; never transliterate them and never translate them as ordinary words. Render 'scratch table' identically in every entry that names it, and do not borrow the database wording for a temporary table. Keep ICU MessageFormat structure, argument names and engine placeholders such as {name} exactly as the source writes them. Use one space between Han text and Latin letters or digits, and fullwidth punctuation inside Han sentences. Avoid textbook jargon: write 默认 rather than 缺省, 缓存 rather than 高速缓存, 延迟 rather than 时延, 分辨率 rather than 解析度, 吞吐量 rather than 吞吐率. Labels are short and never end in a full stop, while help and settings lines are complete sentences. A display-width budget counts cells, where Latin letters and digits count one cell and Han or fullwidth characters count two; a narrow slot must be rewritten shorter, not truncated.</mda:meta>
      </mda:metaGroup>
